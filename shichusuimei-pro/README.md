# 櫻紫式 四柱推命 — 櫻紫オリジナル専用鑑定ツール（完全オフライン）

鑑定士・櫻紫の実務のために誂えた専用ツールです。生年月日と出生時刻から四柱（命式）を立て、
性質・才能・運気の流れを多角的に読み解きます。意匠は「櫻×紫」（江戸紫×桜色）。
**インターネット接続は不要**で、計算からPDF鑑定書の作成まで、すべてがお手元のPC内で完結します。

## 起動方法

`index.html` をブラウザ（Chrome / Edge / Firefox の最新版を推奨）で開くだけで動作します。
インストール・サーバー・ネット接続は不要です。初回起動時にPC環境の自動診断が表示されます。

## 主な機能

### 命式計算
- 四柱（年・月・日・時）、蔵干（月律分野／本気のみ／全蔵干）、通変星、十二運
- 神殺（天乙貴人・天徳貴人・月徳貴人・駅馬・咸池・華蓋・羊刃・魁罡ほか）、十二神殺
- 合冲刑害（干合・支合・三合・半会・方合・冲・刑・害・破）
- 格局（内格・外格〔従格〕）、用神（扶抑）、調候用神、身強身弱、喜神・忌神
- 納音・命宮・胎元・胎息・身宮・透干と通根・空亡（天中殺／旬空）
- 節入りは太陽黄経の天文計算（簡易 Meeus 理論）による時刻精度の判定
- 真太陽時（経度差＋均時差）・地方平均時の時刻補正、時刻不明にも対応
- 旧暦入力（天保暦準拠・閏月対応）と新暦への自動変換

### 流派対応
標準（日本通俗式）・泰山流系・高木乗系・透派系・子平古典系・現代実証系・冬至基準研究系の
7流派プリセットを収録。さらに以下を個別に調整し「マイ流派」として保存できます。

- 年柱の切替（立春／冬至／元日）・日柱の切替（0時／23時）
- 時刻補正（なし／地方平均時／真太陽時）
- 蔵干方式・通変星の表記（標準／古典：七殺・倒食・敗財）
- 大運の順逆・起運の計算・身強身弱の判定・格局の取り方・外格の採用
- 神殺の表示選択・空亡の呼称（空亡／天中殺／旬空）

### 運勢の可視化
- 大運（10年運）・年運・月運（節入り区切り）・日運カレンダー
- 五行レーダーチャート・命式関係図・運勢曲線・ライフチャート（0〜100歳）

### 鑑定
- テーマ別鑑定（総合・恋愛・結婚・仕事・転職・健康・金運）
- 多人数の相性鑑定（全ペア総当たり・スコア付き）
- 鑑定文はエディタで自由に編集可能

### AI搭載（完全オフライン）
- **AI文章仕上げ**: 鑑定文をより自然で読みやすい日本語に整える軽量な日本語文章エンジン
  （トーン: 丁寧／やわらか／格調、要約生成にも対応）
- **AIアシスタント**: 使い方・用語・表示中の命式についてチャット形式で回答
- いずれもPC内で動作し、インターネット送信は一切ありません

### 鑑定士のための実務機能
- 明朝フォントの「櫻紫式鑑定書」PDF（標準／要約／年運／相性・奥付に櫻紫の署名）
  — 印刷ダイアログの「PDFに保存」で保存先を選択できます
- 暗号化された顧客管理（WebCrypto AES-256-GCM + PBKDF2）と顧客DBのバックアップ
- 予約・売上管理（月別集計付き）
- 択日（目的別の開運日さがし）・干支の逆引き・命式のJSON入出力
- 鑑定書のメール下書き作成・初回起動時のPC環境自動診断

## 計算精度と流派差について

- 二十四節気・朔は簡易 Meeus 理論による近似計算です（節気: ±数分程度、朔: ±数分程度）。
  節入り時刻ちょうど近辺の出生は、市販の暦とごく稀に判定が分かれる場合があります。
- 蔵干の日数配分・命宮／身宮の求め方・神殺の採否・身強身弱や格局の判定基準は
  文献・流派により異同があります。本ソフトは代表的な表・方式を採用しつつ、
  設定画面で方式を切り替えられるようにしています。最終判断は鑑定士ご自身の
  流儀に合わせてご調整ください。
- 対応年代: 1900年〜2100年。

## プライバシー

顧客情報・鑑定データ・設定はすべてお使いのブラウザのローカル領域（localStorage）に
保存され、外部へ送信されることはありません。顧客DBはマスターパスワードから導出した
鍵（PBKDF2 20万回 + AES-256-GCM）で暗号化されます。
**マスターパスワードを忘れると復元できません。** バックアップ機能で暗号化された
ままの控えを定期的に保存することをおすすめします。
