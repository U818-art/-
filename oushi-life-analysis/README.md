# 櫻紫 -OUSHI- 人生分析書

「運命を決めつけるのではなく、自分らしく生きるための羅針盤。」

A4縦・印刷前提の人生分析書テンプレートです。全8ページ構成。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | 分析書本体(A4縦・8ページ・印刷用CSS込み) |
| `fonts/` | サブセット済みwoff2フォント(オフラインで完結) |
| `OUSHI_人生分析書.pdf` | 書き出し済みPDF(サンプル) |

## ページ構成

1. 表紙(テーマ・相談者名・作成日)
2. ごあいさつ
3. 第一章 あなたの本質(太陽星座・月星座・数秘術・九星気学・四柱推命)
4. 第二章 あなたとお金の関係
5. 第三章 あなたに向いている働き方
6. 第四章 金運アップのヒント
7. 第五章 今後一年間の流れ(四季)
8. 最後のメッセージ(手書き風・Klee One)

## お客様ごとのカスタマイズ

`index.html` 内の以下を書き換えてください。

- 表紙:`月島 彩乃 様` → 相談者名 / `二〇二六年 七月十八日 謹製` → 作成日
- 表紙:テーマ名 `あなたとお金、そして働き方`
- 第一章の五つの星の値と各説明文、第二〜五章の本文

## PDF書き出し(印刷品質)

ブラウザで `index.html` を開き「印刷 → PDFに保存」
(用紙 A4 / 余白 なし / 背景のグラフィック オン)。

コマンドラインの場合:

```bash
chrome --headless --no-pdf-header-footer \
  --print-to-pdf=OUSHI_人生分析書.pdf index.html
```

## 使用フォント(SIL Open Font License)

- Zen Old Mincho(見出し)
- Shippori Mincho(本文)
- Klee One(最後のメッセージ・手書き風)
