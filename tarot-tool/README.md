# U818 タロット鑑定室（Private）

占い事業の鑑定業務で使う、**あなた専用の非公開タロット占いツール**です。
`index.html` をブラウザで開くだけで動きます（サーバー・ネット接続不要。フォント読み込みのみオンライン時に適用）。

## できること

- **その都度、相談内容を入力して鑑定**
  - 相談者さま（任意）とご相談内容を入力してから展開
  - テーマ：総合運／恋愛・相性／仕事・キャリア／金運／人間関係／健康・メンタル
- **5種類のスプレッド**
  - ワンオラクル（1枚）／スリーカード（3枚）／二者択一（5枚・選択肢A/Bの名前入力可）／ヘキサグラム（7枚）／ケルト十字（10枚）
- **78枚フルデッキ・正逆位置対応**（暗号学的乱数でシャッフル）
- **深掘り機能**：各ポジションごとに補助カードを1枚追加で引いて背景を読める
- **鑑定結果のテキスト化**：ワンクリックでコピーして、お客様への鑑定文の下書きに使える
- **鑑定履歴**：ブラウザ（localStorage）に保存。表示・コピー・削除が可能

## 非公開で使うための注意

- ページには `noindex, nofollow` を設定済み（検索エンジンに登録されません）
- **公開サイト（u818-site）からはリンクしないでください**。リンクしなければ第三者がURLを知る手段はほぼありません
- 確実に非公開にしたい場合は、ネットに置かず **PCやスマホ内のファイルとして開く**のが最も安全です
- 鑑定履歴は「その端末のそのブラウザ」にのみ保存されます。端末を変えると履歴は引き継がれません

## 使い方の流れ

1. STEP 1：相談者さまの情報とご相談内容を入力
2. STEP 2：テーマを選択
3. STEP 3：スプレッドを選択（二者択一のときは選択肢A/Bを入力）
4. 「シャッフルして展開する」→ カードを1枚ずつタップしてめくる（「すべてめくる」も可）
5. 各カードの読み解きを確認。必要なら「＋この位置を深掘りする」で補助カードを追加
6. 全体の読み解きが表示されたら、鑑定メモを記入
7. 「鑑定結果をテキストでコピー」→ お客様への返信文の下書きに
8. 「この鑑定を履歴に保存」→ ページ下部の鑑定履歴に残る
