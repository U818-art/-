# ⑨ 導線改善提案

## 目的

「読まれて終わり」を減らし、記事→フォロー→他記事→商品・サイトへの流れを設計し直す。

## プロンプト

```text
あなたはコンテンツマーケティングの専門家です。
わたしのnoteの導線を診断して、改善案を出してください。

【現状の導線】
- プロフィール文：（貼る）
- 固定記事：【あり/なし。あればタイトルと役割】
- 各記事の結びで案内しているもの：【スキ依頼？フォロー？マガジン？】
- マガジン構成：【 】
- 有料商品・外部リンク（Webサイト、SNS等）：【 】
- 数値（わかる範囲で）：ビュー【 】、スキ率【 】、フォロー転換【 】

【ゴールの優先順位】
1. 【例：フォロワーを増やす】
2. 【例：有料noteの販売】
3. 【例：Webサイト（u818）への流入】

診断してほしいこと：
1. 読者が最初に着地しそうな記事から、ゴールまでの現在の経路を図解（テキストでOK）
2. 途切れているポイント（読者が離脱する場所）の特定
3. 改善案を「今日できること」「今週できること」「今月できること」に分けて提案
4. 各記事の結びに入れる誘導文のテンプレを、ゴール別に3種類

注意：誘導は1記事につき1つに絞る前提で設計してください。
あれもこれも案内する導線は作らないでください。
```

## チェックポイント

- 1記事1誘導になっているか
- プロフィール・固定記事・記事末の3点がすべて同じゴールを向いているか

## コツ

- 導線変更後は2週間データを取ってから次の変更をする（同時に複数変えない）
