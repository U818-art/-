# ⑫ SEOキーワード分析

## 目的

note内検索とGoogle検索の両方から、狙うべきキーワードと記事化の優先順位を決める。

## プロンプト

```text
あなたはSEOとnote運用の専門家です。
わたしの発信テーマでキーワード戦略を作ってください。

【発信テーマ】AI×感性（AI画像生成、AI音楽生成、note運用、ライティング、
AIを使った個人事業・副業）
【読者像】AI初心者。子育て中の女性・副業初心者が中心
【すでに書いた記事のテーマ】
- 【 】
- 【 】

やってほしいこと：
1. 読者が検索しそうなキーワードを40個リストアップ
   - 「ビッグ（1語）」「ミドル（2語）」「ロングテール（3語以上・悩み系）」に分類
   - 例：AI画像生成 / AI画像生成 無料 / AI画像生成 商用利用 注意点
2. 各キーワードに「検索する人の状況（どんな悩みの瞬間か）」を1行で添える
3. 優先順位付け：
   - 競合が強すぎず、わたしの体験談で差別化できるものを上位に
   - 「今すぐ書くべき10個」を選び、それぞれ記事の仮タイトルをつける
4. noteのハッシュタグ戦略：各記事につけるべきタグの組み合わせを提案
   （大きいタグ2つ＋ニッチなタグ3つの構成で）

注意：検索ボリュームの正確な数値はわからなくてよいので、
「検索意図の具体性」を優先して選んでください。
```

## チェックポイント

- ロングテール（悩み系）が半分以上を占めているか（初心者発信はここで勝つ）
- 自分の体験で書けないキーワードが上位に入っていないか

## コツ

- 実際の検索ボリュームは後からラッコキーワード等で裏取りする
- タイトル（④）の前半に狙いのキーワードを置くのを忘れずに
