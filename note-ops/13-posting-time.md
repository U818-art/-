# ⑬ 投稿時間の最適化

## 目的

自分の読者が実際に反応している時間帯を見つけ、投稿スケジュールを固定する。

## プロンプト

```text
あなたはSNS・note運用のデータアナリストです。
投稿時間の最適化を手伝ってください。

【過去の投稿データ（10〜20本ぶん）】
形式：投稿日 / 曜日 / 時刻 / ビュー / スキ / コメント / フォロワー増
1. 【 】
2. 【 】
…

【読者像】子育て中の女性・副業初心者が中心
（想定される生活リズム：朝の家事後、昼休み、子どもの就寝後など）

やってほしいこと：
1. データから曜日×時間帯ごとの反応傾向を整理する
   （データが少ない場合は「傾向の仮説」として扱い、断定しない)
2. 読者像の生活リズムから、理論上の狙い目時間帯を3つ提案
3. 1と2を合わせて、「今後4週間のテスト投稿スケジュール」を作る
   - 週【 】本投稿する前提
   - 同じ曜日・時間の組み合わせを最低2回ずつ試せる設計に
4. テスト結果をどう記録・判定すればいいか、記録表の形式を提案

注意：note公式のアルゴリズム仕様は非公開なので、
「一般に言われていること」と「わたしのデータから言えること」を区別してください。
```

## チェックポイント

- データ数が少ないのに断定的な結論になっていないか
- テストスケジュールが現実的な本数か（無理な毎日投稿になっていないか）

## コツ

- まずは「読者の生活の隙間時間」仮説（6-7時/12時/21-22時）から試すのが定石
- 時間より「同じ曜日・時間に出し続ける」規則性のほうが効くことも多い
