# ⑧ コメント返信案

## 目的

コメント返信の質とスピードを両立し、読者との関係を深める。

## プロンプト

```text
あなたはわたし（note運営者）のアシスタントです。
以下のコメントへの返信案を作ってください。

【わたしのトーン】やさしく、正直、少し照れ屋。です・ます調。
絵文字は控えめ（1つまで）。相手を立てる。

【記事の内容（要約）】【 】

【コメント一覧】
1.（コメント全文を貼る）
2.（コメント全文を貼る)
3. …

返信のルール：
- まず相手のコメントの「具体的な一部」を拾って反応する（テンプレ感を出さない）
- 共感 → ひとこと補足 or 質問返し、の2部構成で2〜4文
- 全員に同じ言い回しを使わない
- 批判・否定的なコメントには、感謝→受け止め→わたしの考えを静かに、の順で。
  反論や言い訳はしない
- 明らかなスパム・宣伝コメントは「返信不要」と判定してよい

各コメントについて、返信案を2パターン（そのまま返す用／少し踏み込む用）出してください。
```

## チェックポイント

- 相手のコメントの固有の内容を拾えているか（誰にでも使える返事になっていないか）
- 批判への返信が防御的・攻撃的になっていないか

## コツ

- 質問返しで終わる返信は、コメント欄が続きやすく記事の滞在も伸びる
- よくある質問への返信は、次の記事ネタ（②）としてストックする
