# ⑲ フォロワー反応分析

## 目的

スキ・コメント・フォローの動きから「読者が本当に求めているもの」を読み取り、次の発信に反映する。

## プロンプト

```text
あなたはオーディエンス分析の専門家です。
わたしのnoteの読者反応を分析してください。

【直近の投稿データ（10〜20本）】
形式：タイトル / テーマ / ビュー / スキ / コメント数 / フォロワー増
1. 【 】
2. 【 】
…

【コメントで多かった声・質問（あれば）】
- 【 】

【フォロワーの傾向（プロフィールを見て気づいたこと）】
- 【例：子育て中の方が多い、AI初心者が多い、など】

分析してほしいこと：
1. スキ率（スキ÷ビュー）で並べ替え、高い記事・低い記事の共通点を抽出
2. 「ビューは多いがスキが少ない」記事の原因仮説
   （タイトルと中身のズレ？ 最後まで読まれていない？）
3. コメントがつく記事とつかない記事の違い
4. フォローにつながった記事の特徴（フォロワー増が多い回）
5. 以上から、読者の本当のニーズを3行で言語化
6. 次の1ヶ月で「増やすべき記事タイプ」「減らすべき記事タイプ」を提案

注意：データが少ない項目は「仮説」と明記し、
検証のために次に何を投稿すべきかをセットで提案してください。
```

## チェックポイント

- ビュー数ではなくスキ率・フォロー転換で判断しているか
- 「仮説」と「事実」が区別されているか

## コツ

- 月末にこの分析を回し、結果を⑳（改善レポート）に流し込む
- コメントの質問は最強のネタ元。②のネタ収集にも転記する
