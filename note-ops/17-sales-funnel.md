# ⑰ note販売導線の改善

## 目的

有料note・メンバーシップ・サービスへの導線を見直し、売り込み感なく自然に買われる流れを作る。

## プロンプト

```text
あなたはコンテンツ販売の専門家です。
わたしのnote販売導線を診断・改善してください。

【売っているもの】
- 商品名：【 】 価格：【 】円
- 内容：【 】
- 買ってほしい人：【 】
- 販売実績：【 部 / 月】

【現在の導線】
- 有料noteの無料部分（試し読み範囲）：（貼る）
- 無料記事からの誘導方法：【記事末にリンク？マガジン？】
- 誘導している無料記事の本数：【 】
- プロフィール・固定記事での扱い：【 】

診断・改善してほしいこと：
1. 無料部分の診断：どこまで見せるべきか。「続きを読みたくなる切れ目」に
   なっているかを判定し、最適な区切り位置を提案
2. 価格の妥当性：内容・読者層・競合相場から見た評価
3. 導線設計：認知（無料記事）→ 信頼（体験談・実績）→ 販売ページの
   3ステップを、いまの記事資産でどう組むか
4. 販売ページ（無料部分）の書き直し案：
   - 誰の・どんな悩みが・どう変わるかを冒頭で
   - 売り込み表現（今だけ、絶対、稼げる系）は使わない
5. 買わない理由の潰し込み：想定される購入のためらい3つと、その解消文

トーンの制約：誠実さ最優先。煽り・希少性の演出・誇大な実績表現はNG。
```

## チェックポイント

- 無料部分だけでも読者の役に立つ構成になっているか（出し惜しみ感はNG）
- 実績・数字がすべて事実か

## コツ

- 「売る記事」は全体の1〜2割まで。残りは信頼を積む無料記事に
- 購入者の感想は（許可を得て）次の販売ページの最強の素材になる
