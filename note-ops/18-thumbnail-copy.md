# ⑱ サムネ文言の提案

## 目的

タイムラインで目を引く見出し画像（サムネ）の文言を作る。タイトルとの役割分担を設計する。

## プロンプト

```text
あなたはサムネイル専門のコピーライターです。
note記事の見出し画像に入れる文言を提案してください。

【記事タイトル】【 】
【記事の要約】【 】
【読者像】【 】
【デザインの雰囲気】やさしい・シンプル・余白多め（U818トーン）

ルール：
- メイン文言：13文字以内（パッと見で読める長さ）
- サブ文言（任意）：15文字以内
- タイトルの丸写しはNG。タイトルと違う角度から興味を引く
  （タイトル＝内容の約束、サムネ＝感情のつかみ、と役割を分ける）
- 数字・カギカッコ・「？」は効果的に使ってよい。煽りはNG

出力：10案。それぞれに
- メイン文言／サブ文言
- 狙い（どんな感情を突くか）1行
- 文字を目立たせる箇所（色や太字にすべき単語）

最後にベスト3を選び、Canva等で作るときの
簡単なレイアウト指示（文字位置・強弱）を添えてください。
```

## チェックポイント

- スマホの小さい表示でも読める文字数か（13文字以内厳守）
- タイトルとサムネで同じ情報を二重に言っていないか

## コツ

- サムネのトーン（色・フォント）は全記事で統一すると、TLで「あの人の記事」と認識される
- 採用しなかった案は⑭（フック）に流用できる
