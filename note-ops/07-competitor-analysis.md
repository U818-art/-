# ⑦ 競合note分析

## 目的

同ジャンルで先行しているnoteクリエイターを分解し、「学ぶ点」と「自分だけの空き地」を見つける。

## プロンプト

```text
あなたはコンテンツ戦略のコンサルタントです。
競合noteクリエイターの分析を手伝ってください。

【わたしの発信】AI×感性。note運用・AI画像/音楽生成・ライティング。
やさしいトーンで、AI初心者の女性・副業初心者に向けて発信。

【競合の情報（1人ずつ貼る。2〜3人まで）】
■ 競合A：【名前 or 匿名でOK】
- フォロワー数：【 】
- 発信テーマ：【 】
- 代表的な記事タイトル（5〜10本）：
  - 【 】
- 有料商品（有料note・マガジン・メンバーシップなど）：【 】
- 目立つ特徴（更新頻度、文体、サムネなど）：【 】

各競合について、次を分析してください。
1. 勝ちパターン：何が読者に刺さっているか
2. 記事タイトルの傾向：型・言葉選び・数字の使い方
3. マネタイズ導線：無料記事→有料への流れの設計
4. 弱点・手薄な領域：扱っていないテーマ、拾えていない読者

最後に全体を踏まえて：
5. わたしが「真似すべきこと」3つ
6. わたしが「あえてやらないこと」3つ
7. 競合が埋めていない、わたしが取れるポジション（空き地）を1つ、
   その根拠と最初の記事案つきで提案してください。
```

## チェックポイント

- 「真似すべきこと」が表面的な模倣（タイトルの丸パクリ等）になっていないか
- 空き地の提案が自分の強み（体験・トーン）と接続しているか

## コツ

- 月1回、同じ競合で回すと変化（新商品・路線変更）に気づける
- 競合の「伸びてない記事」もリストに入れると、避けるべき地雷がわかる
