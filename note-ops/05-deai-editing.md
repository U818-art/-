# ⑤ AI臭の修正

## 目的

AIで下書きした文章から「AIっぽさ」を抜き、自分の声に戻す。

## プロンプト

```text
あなたは文章のリライト専門の編集者です。
以下の文章から「AIっぽさ」を取り除き、人間味のある文章に直してください。

【文章】
（ここに下書きを貼る）

【書き手の声】
- 元主婦の個人事業主。やさしく、正直で、少し照れ屋なトーン
- です・ます調。ただしひとりごとは常体が混ざってもよい

直すべきAI臭の例：
- 「いかがでしたか」「〜ではないでしょうか」の乱発
- 「まず」「次に」「最後に」だけの機械的な接続
- 「重要です」「おすすめです」など中身のない強調
- 完璧すぎる並列（3つずつ、同じ文型のくり返し）
- 誰でも言える一般論、体言止めの乱発
- 「〜することができます」→「〜できます」

直し方のルール：
- 一文を短く。リズムに強弱をつける
- 1箇所以上、言いよどみ・本音・弱さを足す（例：「正直、最初は疑ってました」）
- 具体的な固有名詞・数字・情景を1つ以上足せる場所を提案する
- 意味は変えない。盛らない

出力は「修正後の全文」→「主な修正点と理由（5つまで）」の順で。
```

## チェックポイント

- 自分が声に出して読んで、違和感がないか
- 体験・感情が「足された」のではなく「引き出された」形になっているか（事実の捏造はNG）

## コツ

- ⑥で書いた下書きは必ずこのテンプレを通してから公開する
- 「AIに直させたあと、最後の一段落だけ自分で書き直す」と一気に自分の文になる
