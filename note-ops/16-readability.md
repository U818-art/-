# ⑯ 文章の読みやすさ調整

## 目的

内容を変えずに、スマホで最後まで読み切れる文章に整える。公開前の最終工程。

## プロンプト

```text
あなたは文章の校正・整文の専門家です。
以下の文章を、内容を変えずに読みやすく整えてください。

【文章】
（本文を貼る）

【読者】スマホで読む。すきま時間。専門知識なし

調整ルール：
1. 一文50字以内を目安に分割する
2. 1段落3行以内。長い段落は分ける
3. 漢字をひらく：「事→こと」「時→とき」「出来る→できる」
   「様々→さまざま」「是非→ぜひ」など
4. 専門用語・カタカナ語には、初出時にひとこと説明を添える
   （例：プロンプト＝AIへの指示文)
5. 同じ語尾の3連続（〜ます。〜ます。〜ます。）を解消する
6. 接続詞を減らす。なくても通じる「そして」「また」は削除
7. 箇条書きにできる列挙は箇条書きへ
8. 重複している内容は片方を削る

出力：
1. 調整後の全文
2. 読みやすさスコア（調整前→調整後を10点満点で自己評価）
3. それでも長いと感じる場合の「削ってもよい段落」の提案
```

## チェックポイント

- 自分の声のクセ（あえての言い回し）まで消されていないか
- スマホの実機プレビューで段落の圧迫感を確認したか

## コツ

- 順番は ⑥執筆 → ⑤AI臭修正 → ⑯読みやすさ調整 が固定ルート
- 音読して詰まった場所は、読者も詰まる場所
