# ⑭ フック案の大量生成

## 目的

記事・つぶやきの「最初の1〜3行」を大量に作り、スクロールを止める確率を上げる。

## プロンプト

```text
あなたは書き出し（フック）専門のコピーライターです。
以下のテーマでフック案を30個作ってください。

【テーマ・伝えたいこと】【 】
【読者像】【 】
【使う場所】【note記事の冒頭 / noteのつぶやき / X（旧Twitter） など】
【トーン】やさしく正直。煽らない。嘘・誇張はNG

次の型で各5個ずつ：
A. 悩みの言語化「〜って、しんどいですよね」
B. 意外な告白「実は、〜でした」
C. ビフォーアフター「1年前のわたしは〜。いまは〜」
D. 問いかけ「〜って考えたこと、ありますか？」
E. 情景描写「夜、子どもを寝かしつけたあとの台所で〜」
F. 断言・結論先出し「〜は、しなくていいです」

ルール：
- 各フックは3行以内、1行は20字前後
- 1行目だけで「自分のことだ」と思わせる
- 抽象語（大切、重要、成功）で始めない

最後に、スクロールを止める力が強い順にベスト5を選び、
それぞれ「続きの2文目に何を書くべきか」を添えてください。
```

## チェックポイント

- 1行目に読者の言葉（悩み・状況）が入っているか
- 本文の内容とフックがずれていないか（釣り防止）

## コツ

- ストックしたフックは冒頭だけでなく、見出し・サムネ（⑱）にも流用できる
- 迷ったらE（情景描写）型。U818のトーンと一番相性がいい
