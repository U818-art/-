# ⑳ 改善ポイントのレポート化

## 目的

1ヶ月の運用をふり返り、「続けること・やめること・試すこと」を1枚のレポートにまとめる。

## プロンプト

```text
あなたはわたしのnote運用の参謀です。
今月のふり返りレポートを作ってください。

【今月の数値】
- 投稿本数：【 】（新規【 】/ リライト【 】）
- 総ビュー：【 】（先月比：【 】）
- 総スキ：【 】 / コメント：【 】
- フォロワー：【 】人 →【 】人
- 売上（有料note等）：【 】

【今月やったこと】
- 【例：投稿時間を21時に固定した】
- 【例：サムネのデザインを統一した】

【分析結果の貼り付け（あれば）】
- ⑲フォロワー反応分析の結果：（貼る）
- ①バズ分析の結果：（貼る)

レポートの形式（A4・1枚相当で）：
1. 今月のハイライト（よかったこと3つ、数字つき）
2. 今月の課題（うまくいかなかったこと3つ、原因仮説つき）
3. 学び：今月わかった「わたしの読者に効くこと」
4. 来月のアクション
   - 続けること（Keep）：3つまで
   - やめること（Stop）：1つ以上（必ず何かやめる）
   - 試すこと（Try）：2つまで。それぞれ成功の判定基準つき
5. 来月の数値目標（現実的な1段階上を1〜2個だけ）

トーン：自分を責めない。事実→仮説→次の一手、で淡々と。
```

## チェックポイント

- Try（試すこと）に判定基準（いつまでに・何がどうなったら成功か）があるか
- 目標を増やしすぎていないか（多くて2個）

## コツ

- レポートは毎月同じフォーマットでためると、3ヶ月で自分の勝ちパターンが見えてくる
- このレポート自体を「運用のふり返り」としてnote記事化すると、それもコンテンツになる
